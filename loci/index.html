LOCI

Say it LOH-sigh · Local Offline Cognitive Interface

A voice assistant that runs entirely on your own Mac or Windows PC. LOCI's AI models, speech recognition, voice and notes all stay on your computer, and it works with no internet connection.

See how it installs See the themes

Features

Made for Apple M4

LOCI was built and tuned on an M4 Mac with 16 GB of memory. The M4's built-in GPU and fast shared memory run the AI model, speech recognition and voice together, with no extra graphics card or cloud needed. Any M1 or newer Mac works.

Fully offline

Language models run locally through Ollama, speech recognition through Whisper and the voice through Kokoro. The dashboard shows a live count of cloud calls and data sent, and both stay at zero.

Talk or type

Hold Space to talk, or type in the bar. Choose a female or male voice, with UK and US accents and more.

Instant everyday commands

Timers, opening apps and the time are handled by System One, a fast classifier that answers in milliseconds without waiting for the AI model.

Second brain

Your notes, goals and memories are stored as files on your computer, and LOCI searches them to answer you.

Find your files

Ask for a document and LOCI finds and opens it, searching only the folders you allow.

Optional online hand-offs

Say "ask Claude to …" to pass a bigger job to Claude Code or Codex. These are off unless you install and sign in to those tools yourself.

Three looks

Switch themes any time with the THEME button. Above is x-cpu, the default.

Install

Mac

  1. Install Homebrew if your Mac doesn't already have it.
  2. Download loci.zip, double-click it, and move the loci folder into Documents.
  3. Open Terminal and run:
    cd ~/Documents/loci && ./install.sh
  4. Answer the three questions: where to keep the models, what LOCI should call you, and which voice you want. The download takes a while the first time.
  5. Run ./start.sh. Your browser opens the dashboard. Click ENGAGE and allow the microphone.

To start LOCI automatically when you log in, run ./install-always-on.sh.

Windows

  1. Download loci.zip, right-click it, choose Extract All, and extract it to Documents.
  2. Open Terminal or Windows PowerShell. Don't use PowerShell ISE.
  3. Run:
    cd ~\Documents\loci
    powershell -ExecutionPolicy Bypass -File .\install.ps1
  4. Approve the one administrator prompt (for Node.js), then answer the same three questions.
  5. Run powershell -ExecutionPolicy Bypass -File .\start.ps1 and keep that window open. Click ENGAGE in the browser.

The installer checks your graphics card and chooses the right model size.

Updating

Download the new loci.zip and copy its contents over your loci folder, then run the installer again. Your settings (config.json) and your notes (brain/) are kept.

FAQ

Is this like JARVIS from the movies?

That's the idea: a talking assistant with a glowing HUD that knows your notes and runs your errands. Unlike the movie version, LOCI runs on your own computer and keeps everything to itself. LOCI is an independent project and isn't affiliated with Marvel or Disney.

Does anything leave my computer?

No. Models, speech and notes are all local, and there are no analytics. The only exception is a hand-off ("ask Claude to …"), which you have to set up yourself. Hand-offs send that one request to Claude Code or Codex.

Why is the first answer slow?

The first time after LOCI starts, the model has to load into memory. Later answers start in about a second. On Windows, the very first start after installing can take about two minutes.

It says "Another Ollama is running".

Quit the Ollama app from the menu bar or system tray, then start LOCI again. LOCI runs its own copy of Ollama with its own models folder.

The browser shows a microphone error.

Connect a microphone, select it in your computer's sound input settings, and allow microphone access for localhost in the browser.

It mishears a name.

Add the word to vocabulary in config.json and restart LOCI.

Windows says "running scripts is disabled".

Run scripts in the form powershell -ExecutionPolicy Bypass -File .\script.ps1, as shown in the install steps.

The dashboard won't load, or a port is in use.

Stop LOCI and start it again. Security or VPN software can take LOCI's ports; running the installer again picks free ones. Logs are in the .logs folder.
